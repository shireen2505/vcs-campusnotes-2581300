\# CampusNotes



CampusNotes is a simple text-based project for organising academic information.



\## Project Files



| File | Purpose |

|---|---|

| subjects.txt | Stores subject names |

| timetable.txt | Stores the study timetable |

| goals.txt | Tracks academic goals |

| study-tracker.txt | Records study progress |



\## Usage



Open the text files in any text editor to view or update your study information.



\## Purpose



To keep subjects, schedules and academic goals organised in one place.
